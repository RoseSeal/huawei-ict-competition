## 4. 逐例要点

- **Q01**：双方均避免了两类典型错误——只按里程判"影响 C"（证据不足）和漏看延期判"不影响"。模型明确写出"延期后有效期至 09-30"并据以判定时间命中。
- **Q05**：双方均未把 0066 的 0700—1800 套用到 2025-07-10（0066 未引用 0098，不合并）——这正是协议 r1-2 与提示词"不能把局部变更视为全文废止"针对的陷阱。
- **Q06**：均判信息不足，但**推演路径不同**：模型先判 0094 已届满再判延期对象冲突；r1 按规则 2 直接因引用冲突输出。结论一致、理由不同，符合协议"不只统计总体准确率"的要求。
- **Q07/Q08**：江段型判定依赖人工在输入中注明（r1-4 允许）；模型的船型豁免推理完整，且把"服从现场指挥"正确归为一般要求。

## 5. 能否由简单规则解决（协议要求的报告项）

| 环节 | r1 可解 | 说明 |
|---|---|---|
| 延期继承与时段沿用 | ✅ | 结构化的引用关系+日期字段即可 |
| 新发通告不合并 | ✅ | 规则 2 显式覆盖 |
| 每日时段比较 | ✅ | 纯字段比较 |
| 引用冲突检测 | ✅ | 标题与文号一致性可脚本化 |
| 活动船舶豁免 | ✅ | 船型字段匹配 |
| **空间相交判断** | ⚠️ **依赖人工输入几何** | 局部型四边形与航路的相对位置，r1 无法自动判定（r1-4 明确此为人工成本）；本批 5 例靠"时间不命中"或"人工注明江段型"绕开，**未真正考验空间推理** |
| **非结构化原文→结构化字段** | ❌ | 0094 全文缺失、0033 冲突的识别，前提是有人先把原文读成字段——本试验的输入已是人工整理后的字段 |

**诚实的结论边界**：5 例小样本 + 输入已人工结构化 + 模型参数不可控。本试验**支持**的结论仅限："在该批结构化输入上，会话级强模型与确定性规则 r1 均能达到与 A4 标注一致的结果；两者的价值差异未在本样本中显现。"**不支持**"强模型必要"或"简单规则不足"或"泛化提升"中的任何一条。真正的难点（原文→字段抽取、局部型空间推理）在 A3 交付航路几何、并扩充含未结构化原文的案例集之前，无法被本试验覆盖。
