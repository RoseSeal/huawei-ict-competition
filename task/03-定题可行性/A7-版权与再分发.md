# A7 网站版权与开源再分发核查

核查日期：2026-11-09（北京时间）。本报告记录已取得的官方声明与工程决策建议，未取得站方个别授权。

**结论：不能把官网可公开访问当作允许将整页 HTML、图片、附件或通告数据集以项目开源许可证再分发的证据。长江海事局声明有明确转载限制，但也不能将其简化为“所有非商业转载绝对禁止”。本项目应在逐项确定权利或取得授权前，将原始网页证据保留为本地核查材料，不纳入公开仓库发布。**

## 适用范围与不能扩张的部分

| 项目 | 判定 |
|---|---|
| 本站原创内容 | 声明主张版权归本网站；未出现开源许可证或广泛再分发授权 |
| 本站转载内容 | 版权归源网站；不能仅取得本站同意便认为全部权利齐备 |
| 其他单位提供的信息与服务 | 声明要求直接联系相应提供单位取得合法授权 |
| 商业性原版原式转载 | 声明明确禁止；“不收费”“放GitHub”不自动证明后续用途非商业 |
| 非商业转载 | 不能从第一段禁止商业性转载反向推导出无限制授权，仍须结合内容类型、来源与其他条款判断 |
| 长江航道局 / 武汉航道局通告 | 不是此声明所属网站；不得套用此声明作为允许或禁止的最终依据 |
| 国家海事局及其他直属海事局网站 | 未在本次确认其各自版权全文；不能用长江海事局条款代表所有海事网站 |

声明中的版权主张也不替代逐条法律性质分析；特定行政文件是否属于不适用著作权保护的文件、抽取事实是否构成受保护表达，应逐项判断。本次未核实相应法规全文，也未对每份通告完成法律分类，不能宣称全部通告均属公有领域。

## 对开源仓库的具体回答

- **项目自行编写的代码、解析逻辑、合成测试样例**可以与外部数据分开管理许可；本报告没有审核现有代码许可证，不代替代码许可审查。
- **链接、来源标识、访问日期、原文哈希**适合用作追溯索引；不要把“有URL”“已标注来源”视为替代复制授权。
- **原始HTML、页面截图、图片、附件和批量正文快照**：当前没有证明可整体公开再分发的授权依据；本地研究留存不意味着允许公开上传。避免把站点logo、样式和第三方图片并入项目许可证。
- **结构化抽取结果**：不因转换为JSON/GeoJSON自动获得再分发权。应区分事实字段、长段原文引用、版权性内容和第三方数据，保留出处并单独确认数据许可。
- **少量必要原文引用**用于说明本次核查结论，不能扩展为整库授权；本报告引用声明是记录依据，不构成对原站内容的再许可。

建议的发布方案：公开代码、合成样例及来源清单；实际原文快照和未经确认的数据包先作为本地材料；若确需公开数据集，向内容提供单位书面确认批量复制、结构化转换、公开下载、商用/再分发及与目标开源许可证的兼容范围。取得明确授权后再将授权文件、来源和许可证随数据一并记录。

## 与当前项目计划的关联

项目v1.3总览提出通告HTML快照入仓。内部版本库留存与公共开源发布是不同动作；“入仓”目标不能替代来源许可核查。项目主要使用长江武汉航道局航标通告，而本报告核实的是长江海事局声明，因此对项目现有航道局快照的公开发布仍需其站点独立结论。本报告不修改计划或业务代码，也没有执行删除、提交、推送或发布。
