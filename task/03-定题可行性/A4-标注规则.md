# A4 标注规则：通告是否影响航次

> 2026-11-04 修订版。用于 [A4](README.md) 试标，试标题目见 [A4 试标查询](A4-试标查询.md)。规则修订与试标后的补充记在第 6 节。
> 示例所用通告原文的查询日期均为 2026-11-04，来源见第 7 节。

## 1. 标注对象

**一个查询＝一个航次 × 一条通告链。**

- **航次**：航线、通过各水域的时间、船舶条件。取得方式见 [A2](A2-航次输入.md)；示例中的航次均为情景设定。
- **通告链**：由引用关系（延期、变更、废止、解除、“仍按某号执行”）连在一起的一组通告。没有引用其他通告、也没有被引用的通告单独成链。同一工程的多份通告，如果相互之间没有引用，分别成链、分别标注。
- **查询时刻**：发出查询的时刻，一般取出发时刻。只纳入发布时间不晚于查询时刻的通告。

一份通告可能对不同船舶、航向、时段、位置提出不同要求，因此先按**条款**判断，再汇总到整条链。每个查询输出：

| 字段 | 取值 |
|---|---|
| 条款判断 | 每条约束过往船舶的条款：空间、时间、船舶条件各填“是／否／不确定”，得出“适用／不适用／不确定”，附原文依据 |
| 结论 | 影响／不影响／信息不足 |
| 影响等级 | 结论为“影响”时填写：A 禁止驶入／B 限制通行／C 谨慎通过 |
| 缺失信息 | 存在“不确定”时，写明原因类别和具体内容 |

## 2. 判定流程

### 步骤 0：整理通告链，按条款列出有效内容

1. **向前回溯**：沿“仍按某号执行”等引用，逐级找到原通告全文。
2. **向后检索**：按工程名称和文号，检索有无后续的延期、变更、废止、解除通告，以及同一工程的新通告。记录检索渠道、关键词和检索日期。
3. **按查询时刻筛选**：只保留发布时间不晚于查询时刻的通告。
4. **合成有效内容**：后发通告只替换它明确写出的事项，其余沿用被引用的通告。例如延期通告只改截止日期，水域、每日时段和要求沿用原通告。
5. **新发通告不合并**：同一工程重新发布的通告，如果没有引用旧通告，按各自原文判定，不把旧通告的条件带进来，也不把新通告的条件套用到旧时段。
6. **引用冲突**：引用的标题与文号指向不同通告，或者同编号原文与引用内容不符时，记为冲突。两种解读得出的结论相同，可以下结论并注明；结论不同，依赖继承内容的条件判“不确定”。
7. **列出条款**：把约束过往船舶的条款逐条列出，每条写明：
   - 适用对象：船种、吨位、载况、航向；
   - 时段；
   - 位置：整个通告水域，或其中某处（如“窑咀水域”）；
   - 要求类型：驶入类或航经类，见步骤 2；
   - 等级，见步骤 4；
   - 出处：哪一号通告的哪一条。

   以下条款不参与判定：只约束施工单位或施工船舶本身的条款，以及“施工结束不另发通告”一类说明。“及时调整运输计划”“服从现场指挥”等一般性要求，记入备注，不单独定级。

### 步骤 1：空间——航路是否经过适用水域

先按水域的界定方式分类：

| 水域类型 | 例子 | 判“是”的条件 |
|---|---|---|
| **江段型**：按里程段、两处地物之间界定，或几何上横跨整个通航江面 | 汉航通〔2026〕0035 号“67 km 至 58 km 之间水域”；034 号“武汉长江大桥至二七长江大桥之间水域” | 航线经过该江段 |
| **局部型**：只占部分江面的多边形或点位，如岸侧施工区、码头前沿、锚地 | 汉航通〔2025〕0066 号右岸侧约 396 m × 150 m 的四边形 | 航路几何与该水域相交，或者原文有适用于整段过往船舶的条款 |

| 情形 | 判定 |
|---|---|
| 航线不经过该江段或里程段 | 否 |
| 江段型水域，航线经过该江段 | 是 |
| 局部型水域，航路几何与水域相交 | 是 |
| 局部型水域，航路几何确定不与水域相交，且原文没有适用于整段过往船舶的条款 | 否 |
| 局部型水域，缺航路横向位置或水域几何 | 不确定（材料缺失） |
| 地名、桥梁、里程无法定位，或者航线在该处有多种走法而查询未写明 | 不确定（材料缺失） |

- **里程重合只用于筛选候选通告**，不能作为局部型水域的命中依据。“原文未写明位于航道外”也不能替代航路与作业区的相对位置。
- 原文给出多边形，但没写明横跨江面的，按局部型处理；A3 核算表明它覆盖整个通航江面后，才改按江段型处理。
- 条款另限定位置的（如“上行通过窑咀水域”），按该位置判断。
- **航路几何**：来自 A2 计划航线和 A3 航道中心线或推荐航路。A3 交付前，局部型水域一般只能判“不确定”。
- **水域定位**：
  - 有坐标的，按原文顺序连点成多边形；连线自交时改用四点凸包，并注明这一处理。
  - 只有里程的，用航道里程段表示。
  - 只有桥梁、地名的，用两处地物之间的江段表示。
  - 记录所用底图或坐标资料的来源（与 A3 共用）。

### 步骤 2：时间——是否落在有效时段内

**先写出三个时间量**：

| 时间量 | 含义 |
|---|---|
| 驶入时刻 | 船首到达该水域（或条款所限位置）的时刻 |
| 占用时段 | 从驶入到驶出该水域的区间 |
| ETA 区间 | 由流速等不确定性带来的可能取值，至少写出最快、标称、最慢三种情形 |

**再确定有效时段**：有效期叠加每日时段，如“每日 0700—1800”。时间均按北京时间，起止时刻都包含在内。

- **有效期的起止按查询时刻可见的通告确定。**管制已经开始、结束时间“另行通告”或“视情况决定”，而查询时刻还没有看到解除通告的，按生效中处理。
  - 例：A2 的 Q3 查询时刻为 07-05 10:00，只能看到岳航通〔2026〕0021 号；0022 号解除通告 07-08 17:09 才发布，0021 按生效处理。
- 查询时刻已经能看到解除或废止通告的，按其写明的解除时刻截止。
- “施工结束，不另发通告”：在通告期限内按有效处理，不推断提前结束。
- 期限届满后，检索未见延期通告，按失效处理，并记录检索范围和检索日期。没有做后续检索的，判“不确定（材料缺失）”。

**最后按条款的要求类型比较**：

| 要求类型 | 例子 | 比较方法 |
|---|---|---|
| 驶入类：禁止进入或通过 | “不得驶入”“禁止任何船舶驶入”“禁止交通船航经管制水域”“禁止……夜间上行通过窑咀水域” | 只比较驶入时刻（条款限定位置的，比较到达该位置的时刻） |
| 航经类：在水域内须如何航行 | “航经时加强了望、安全航速通过”“禁止追越、淌航”“平舱后方可通过” | 比较占用时段与有效时段是否重叠 |

| 情形 | 判定 |
|---|---|
| 驶入类：驶入时刻在禁入时段内 | 是 |
| 驶入类：驶入时刻在时段后；或驶入、驶出都在时段开始前 | 否 |
| 驶入类：时段开始前已驶入、开始后才驶出（管制开始时船已在区内） | 不确定（原文未覆盖） |
| 航经类：占用时段与有效时段有重叠 | 是 |
| 航经类：占用时段与有效时段没有重叠 | 否 |

- **原文未覆盖**：驶入类条款只限制驶入。管制开始时船已在区内、原文又没规定如何处理的，不能由“不得驶入”推出须等待，也不能判为不受约束。
  - 例：A2 的 Q0 中，034 号的禁入时段为 20:00—23:00。标称情形 20:31 驶入，判是；最快情形 19:43 驶入、20:11 驶出，属原文未覆盖。
- **ETA 区间**：最快、标称、最慢三种情形分别判定。结论一致，取该结论；不一致，判“不确定（输入不确定）”，并写明结论在哪一种情形、因什么改变。
- **规划策略不进入标注**：标注只按原文条款判定，记为 S0。“须在管制开始前驶出，否则在区外等待”等做法是规划层面的假设，记为 S1；需要时单独标为情景假设，不写入标注结论。

### 步骤 3：船舶条件——本船是否属于约束对象

逐条款比较船种、吨位、尺度、吃水、载况、航向等条件。

| 情形 | 判定 |
|---|---|
| 条款面向“各船舶”“任何船舶”“所有船舶”，未设其他条件 | 是 |
| 条款设有船舶或航向条件，本船全部满足 | 是 |
| 本船有任一条件不满足，或者属于排除对象，如活动船舶、施工船舶本身 | 否 |
| 条款设有条件，而查询缺少相应的船舶信息 | 不确定（材料缺失） |

- 例：0021 第四条（一）前句的对象是“1000 总吨及以下重载船”“夜间”“上行通过窑咀”。A2 设定的本船为 900 总吨、重载，吨位和载况满足；但本船下行、白天通过、不经过窑咀，所以该条不适用。逐条款拆分见 A2 §5.2。

### 步骤 4：合成结论与影响等级

**条款判定**：

| 三项条件 | 条款 |
|---|---|
| 均为“是” | 适用 |
| 任一项为“否” | 不适用 |
| 其他情况 | 不确定 |

**链结论**：

| 条款情况 | 结论 |
|---|---|
| 至少一条适用 | 影响，等级取适用条款中最严格的一级 |
| 全部不适用 | 不影响 |
| 没有适用条款，至少一条不确定 | 信息不足 |

- 结论为“影响”，而另有不确定条款的等级更高时，等级写成“C（可能 A）”这样的形式，并在缺失信息中写明。
- 三项条件都要填写，便于核对分歧。
- 一个航次涉及多条链时，逐链标注，汇总时取最高等级。
- “不确定”的原因按四类填写：
  - **材料缺失**：原文、航路几何、ETA、船舶信息、后续检索；
  - **引用冲突**；
  - **输入不确定**：ETA 区间两端结论不同；
  - **原文未覆盖**。

**影响等级**：

| 等级 | 原文要求举例 |
|---|---|
| A 禁止驶入 | 禁航、封航、“不得驶入”“禁止任何船舶驶入”、禁止某类船舶航经或通过 |
| B 限制通行 | 单向通航、限速或最低航速、禁止追越与淌航、尺度限制、须平舱或满足其他条件后方可通过、须申请或经指挥放行 |
| C 谨慎通过 | 加强了望、谨慎操作、安全航速通过、及早联系会让、保持安全距离 |

## 3. 记录表

每个查询填一份；试标时各自填写，不互相参考。

**查询信息**

| 字段 | 填写内容 |
|---|---|
| 查询编号 | 如 T01 |
| 航次 | 航线（起止点、经过的水道或里程段）、船舶条件、情景设定说明 |
| 时间量 | 各水域的驶入时刻、驶出时刻，分最快、标称、最慢三种情形 |
| 查询时刻 | 年月日时分 |
| 通告链 | 文号按引用顺序排列，如 0066 ← 0026；注明各号是否在查询时刻可见 |
| 后续检索 | 渠道、关键词、日期、结果 |

**条款判断**（每条约束过往船舶的条款一行）

| 条款 | 要求 | 类型 | 等级 | 空间 | 时间 | 船舶条件 | 条款判定 | 依据 |
|---|---|---|---|---|---|---|---|---|
| 0066 五（二） | 航经时加强了望…… | 航经类 | C | 是／否／不确定 + 理由 | 同左 | 同左 | 适用／不适用／不确定 | 条款出处、所用时间量 |

**结论**

| 字段 | 填写内容 |
|---|---|
| 结论 / 等级 | 影响 A/B/C、不影响、信息不足 |
| 缺失信息 | 原因类别 + 具体内容；可能的结果，如“可能为影响 C” |
| 原文依据 | 链接或文件路径，引用到条款 |
| 标注人 / 日期 | |
| 备注 | 一般性要求、处理方式、易错点、规则未覆盖的情形 |

## 4. 示例材料：汉南过江通道通告

武汉海事局为武汉都市区环线汉南过江通道施工发布的通告，2024—2026 年间形成以下关系。水域均在长江中游水洪口水道，航道里程约 58—67 km。

```text
南岸主塔:  2024-0098 ← 2025-0031(延期至2025-12-31)
           2025-0066 ← 2026-0026(延期至2026-09-30)          [0066 为新发通告，未引用 0098]
北岸主塔:  2024-0094 ← 2025-0033(延期；引用标题写“南岸”，文号写 0094)
           2025-0067 ← 2026-0027(延期至2026-09-30)
同一工程单独成链:  2026-0035(先导索过江管制)、2026-0036(猫道及主缆施工)
```

| 文号 | 发布日期 | 有效内容 | 水域类型 | 要求 | 等级 |
|---|---|---|---|---|---|
| 汉航通〔2024〕0098号 | 2024-12-09 | 2024-12-10—2025-06-30，每日 0800—1700；右岸侧，里程约 63.6—64.0 km，四点坐标 | 局部型 | 加强了望、安全航速通过 | C |
| 汉航通〔2025〕0031号 | 2025-06-27 | 延期至 2025-12-31，其余按 0098 | 同 0098 | 同 0098 | C |
| 汉航通〔2025〕0066号 | 2025-12-31 | 2026-01-01—06-30，每日 0700—1800；水域与 0098 相同（同一组四点，列出顺序不同） | 局部型 | 加强了望、安全航速通过 | C |
| 汉航通〔2026〕0026号 | 2026-06-30 | 延期至 2026-09-30，其余按 0066 | 同 0066 | 同 0066 | C |
| 汉航通〔2024〕0094号 | 2024-12-02 | 2024-12-03—2025-06-30，每日 0700—1800；左岸侧，里程约 63.7—64.2 km | 局部型 | 未取得全文，以搜索结果摘要为准 | — |
| 汉航通〔2025〕0033号 | 2025-07-02 | 延期至 2025-12-31；引用北岸工程，但写的是南岸通告标题和 0094 文号 | — | — | — |
| 汉航通〔2026〕0035号 | 2026-10-29 | 2026-10-30 09:00—13:00；里程 58—67 km 之间水域 | 江段型 | 禁止任何船舶驶入 | A |
| 汉航通〔2026〕0036号 | 2026-10-29 | 2026-10-30—12-31，每日 0800—1700；里程约 63.8—64.1 km，长约 1400 m、宽约 300 m | 局部型，待 A3 核实是否横跨江面 | 加强了望、安全航速通过 | C |

这组材料覆盖了标注中的几类难点：

- **延期继承**：0026 正文只有一句话，水域和每日时段都要回溯 0066。
- **新发通告改了条件**：0066 未引用 0098，每日时段由 0800—1700 改为 0700—1800。
- **引用冲突**：0033 的引用标题与文号不一致。
- **同一工程的高影响通告**：0035 禁止任何船舶驶入，而同工程的其他通告只要求谨慎通过。
- **局部水域**：0066、0098 的施工区只占右岸一侧，判断空间需要航路的横向位置，不能只看里程。
- **坐标顺序**：0098 的四点按原文顺序连线会自交，0066 换了顺序后才是约 396 m × 150 m 的四边形。

另用 [汉航通〔2026〕034 号](https://www.mot.gov.cn/fuwu/yujingtishi/cjhangxingtonggao/202609/t20260929_4225146.html) 补充船型判断：

- 管制时间：2026-09-30 20:00—23:00，2026-10-01 17:00—21:00。
- 管制水域：武汉长江大桥至二七长江大桥之间水域，及汉江晴川桥以下水域。属江段型。
- 管制要求：“除活动船舶外，其他船舶不得驶入管制水域”。属驶入类，等级 A。

## 5. 完整示例

### 5.1 Q01 逐步标注

**查询**

- 航次（情景设定）：散货船，不载危险货物；武汉→岳阳上行，沿主航道经水洪口水道。
- 时间量：通过里程 64.0—63.6 km 段，最快、标称、最慢三种情形的占用时段合计落在 2026-07-20 09:45—10:25 之间。
- 航路横向位置：未给出，A3 未交付。
- 查询时刻：2026-07-19 20:00。
- 通告链：汉航通〔2025〕0066号 ← 汉航通〔2026〕0026号。

**步骤 0：整理通告链**

1. **向前回溯**：0026 写明“其他相关事宜仍按……（汉航通〔2025〕0066号）执行”，取得 0066 全文。0066 未引用其他通告。
2. **向后检索**：2026-11-04 在长江海事局站内搜索“汉南过江通道”，按时间排序。2026-06-30 之后只有 0035、0036 两份通告，都是新发通告，没有南岸主塔施工的再次延期或变更。
3. **查询时刻检查**：0066（2025-12-31）和 0026（2026-06-30 16:26）都早于查询时刻，纳入。
4. **合成有效内容**：

| 事项 | 有效内容 | 出处 |
|---|---|---|
| 有效期 | 2026-01-01—2026-09-30 | 起始日：0066 第一条；截止日：0026 |
| 每日时段 | 0700—1800 | 0066 第一条 |
| 水域 | 水洪口水道右岸侧，里程约 63.6—64.0 km，长约 396 m、宽约 150 m，四点坐标；局部型 | 0066 第二条 |

**步骤 1：空间 → 不确定（材料缺失）**

- 施工水域是右岸侧的局部四边形，宽约 150 m，原文没有写明横跨江面。
- 查询只给出“沿主航道经水洪口水道”，没有航路横向位置，无法判断航路是否经过作业区。
- 里程段重合只能说明 0066 是候选通告。

**步骤 2：时间 → 是**

- 日期 2026-07-20 在有效期 2026-01-01—09-30 内。
- 航经类条款比较占用时段：三种情形的占用时段都在每日 0700—1800 内。
- 依据：0026 正文，0066 第一条。

**步骤 3：船舶条件 → 是**

- 条款面向各船舶，未设排除对象。

**步骤 4：结论 → 信息不足**

- 唯一条款判为“不确定”，没有适用条款。
- 缺失信息：材料缺失，缺航路与右岸作业区的相对位置，待 A2 航线与 A3 航道几何。
- 可能结果：航路经过作业区时为影响 C；航路确定不经过时为不影响。

**易错点**

- **只按里程判定**：会得出“影响 C”，但证据不足，里程重合不等于航路经过作业区。
- **只读 0066**：会得出“有效期至 6 月 30 日，7 月 20 日时间否、不影响”，漏掉了延期。
- **只读 0026**：正文没有水域和时段，必须回溯 0066 才能判断。
- **查询时刻改为 2026-06-29**：0026 尚未发布，只纳入 0066，时间判“否”，结论为“不影响”。0026 发布后，时间改判“是”，这一类“新通告改变既有结论”的情形可供 A5 选用。
