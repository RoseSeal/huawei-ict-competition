# 失败场景

## 目的

找出现有系统在异常输入下的错误行为，作为后续评测的初始用例。

## 交付

- 3 张场景卡，每张包含：输入变化、正常对照、预期行为及依据、复现步骤、实际结果。
  - 只看卡片即可复现。
  - 预期行为在运行前写好（git 存证早于验证运行），并按[评测判据](../评测判据.md)注明依据。
  - 三张卡已于 2026-11-04 由两名成员**双机独立验证**并交叉比对（场景 01 预期未满足，构成失败用例；场景 02 基本符合预期；场景 03 符合预期），原始日志见[运行证据](运行证据/)，本机日志归档于 `exp-logs/`。
- 一次本地运行记录：运行结果或具体阻塞（含 2026-10-30 首次运行与 2026-11-04 双机失败场景验证两部分）。
