## 重要更正：Clip-10.zip ≠ V1.0 的 "Video-10"

GitHub README 表格中的 "Video-10（3 艘船 / 1 艘有 AIS）" 与本包中的 `clip-10` **不是同一视频**（本包 clip-10 实测 4 艘可见 / 4 艘有 AIS）。Clip-10.zip 是独立发布的 10 段样本剪辑（clip-01~clip-10），编号体系与 V1.0 完整包不同。**要找 README 表格里"有 AIS 盲区"的示范视频，需下载 V1.0 完整包（40 GB）**。

## 一、数据格式实测（更正 README 描述）

| 文件 | 实测格式 | 备注 |
|---|---|---|
| `gt_tracking.txt` | MOT：`frame, id, left, top, w, h, conf, cls, vis` | id = 轨迹号 |
| `gt_fusion.txt` | `frame, nanosecond, left, top, w, h, conf, cls, vis` | **没有 id 列**：id 被换成 AIS 报文时间（纳秒），船的身份须按 `(frame, left, top)` 与 tracking 精确对齐 |
| `ais/*.csv` | 每秒一文件，列：`mmsi, lon, lat, speed, course, heading, type, timestamp(ms)` | timestamp 为 **UTC 毫秒**（按 UTC+8 换算后与文件名/视频窗一致） |

## 三、时间对齐实测（回答任务问题 2）

以 clip-10 为例：
- 视频文件名时间窗 `2022-11-20 10:18:21 ~ 10:21:07`（本地时间）
- AIS 报文 epoch 按本地时区换算后覆盖 `09:48:41 ~ 10:21:28`，与 CSV 文件名（每秒一文件）完全吻合
- **结论：AIS 时间戳为 UTC 毫秒、视频文件名为 UTC+8 本地时间，两者可直接对齐，无未知时区偏移**

## 四、AIS 与视频的互补性（clip-10 实测）

- 视频窗内 AIS 接收机听到 **37 个不同 MMSI**（5315 条报文）
- 同一窗口相机只看到 **4 艘船**
- ⇒ AIS 的射频覆盖（含雷达视距外/远处小目标）远超相机视场；反过来相机能看到 AIS 收不到的船（本样本 10 段中未出现，但 README 的 V1.0 表格记载了此类视频，如 Video-10）

## 五、对任务核心问题的回答

> **2026-11-03 更新：V1.0 完整包（40.9GB）已下载并完成 26 段视频全量普查，本节结论已从"待验证"升级为"已核实"。见 [本地运行记录-数据集获取与全量普查.md 第四节](本地运行记录-数据集获取与全量普查.md)与 [V1.0普查-结果.csv](V1.0普查-结果.csv)。**

**FVessel 能否作为 AIS 之外的数据源，覆盖没开 AIS 的船？——能，已实测证实。**

- 26 段视频中有 **7 段**存在无 AIS 船（Video-18 最多：10 艘可见 / 4 艘无 AIS；Video-10 证实了 README 的说法：3 艘可见 / 1 有 AIS / 2 无 AIS）；
- 合计 11 艘无 AIS 船拥有逐帧图像级 GT 轨迹，可与 AIS 数据在同一时间轴上对齐；
- 以下两条为对 Clip-10 样本包的历史结论，仍然成立：

1. **数据结构上可以**：tracking（全部可见船）与 fusion（有 AIS 的船）通过 bbox 可精确对齐（本样本匹配率 100%），差集即无 AIS 船舶；时间对齐无障碍。
2. **但 Clip-10.zip 样本本身没有 AIS 盲区案例**（10 段全部可见船都有 AIS），且视频时间为 2022-05~11 固定快照、MMSI 已匿名化——只能作**离线评测源**，不能作 map-system 的实时输入。
3. **要实际构造"无 AIS 船"评测用例，需下载 V1.0 完整包（40 GB）并按 README 表格定位有盲区的视频**（如 Video-10：3 艘可见 / 1 艘有 AIS）。

## 六、下载与环境阻塞记录（本地运行记录素材）
